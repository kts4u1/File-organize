툴 검교정 정리

검교정 후 찍은 툴 사진에서 시리얼과 교정필증 날짜를 읽어, Tool Verification 엑셀의 해당 엔지니어 행에 날짜를 고치고 교정필증 사진을 넣습니다.

파일과 사진은 이 브라우저 안에서만 처리합니다. API 키나 서버가 필요 없습니다.

STEP 1

Tool Verification 엑셀

STEP 2

검교정 사진 · SMAX 캡쳐

이름·시리얼 메모(또는 QR 스티커)와 교정필증이 한 장에 나오게 찍은 사진. 여러 장 한꺼번에 올려도 됩니다.
가상의 엑셀과 예시 사진 2장(QR 스티커, 손글씨 메모)으로 전체 과정을 보여줍니다.
STEP 1에서 엑셀을, STEP 2에서 사진을 고르면 사진마다 찾은 툴과 날짜가 여기에 나옵니다. 확인한 뒤 엑셀 파일을 만듭니다.
'자동 반영'은 바로 들어가고, '확인 필요'는 내용을 보고 체크하면 들어갑니다.
