# 툴 검교정 관리 (Tool Calibration Photo → Excel)

엔지니어 툴(멀티미터, 토크렌치, 안전분석기 등)의 **검교정 후 사진**을 올리면

1. 사진 속 **QR 스티커 또는 손글씨 메모(시리얼·이름)** 와 **교정필증(교정일자 / 차기교정예정일자)** 을 읽고
2. `Tool_Verification` 엑셀에서 **해당 엔지니어의 툴 행을 찾아**
3. **Cal Last / Cal Next 날짜를 수정**하고, **Label Photo 칸의 사진을 교정필증 사진으로 교체**합니다.

SMAX 화면 캡쳐를 같이 올리면 `SMAX Tool Photo` 칸도 교체합니다. `Due date 현황`에서 만료/임박 툴을 보고,
`QR 스티커`에서 툴에 붙일 이름·시리얼·QR 스티커(A4 PDF)를 만듭니다.

두 가지 버전이 있습니다.

| | 브라우저 버전 (`web/`) — **권장** | Python 버전 (`app.py`, `toolcal/`) |
|---|---|---|
| 설치 | 없음 (링크만 열면 됨) | Python + `install.bat` |
| API 키 | **필요 없음** (브라우저 안에서 글자 인식) | 선택 (Claude API를 쓰면 손글씨 인식이 더 정확) |
| 손글씨 시리얼 | 오프라인 OCR + 엑셀 시리얼 목록과 대조 → 애매하면 '확인 필요' | Claude 비전으로 판독 |
| QR 스티커 | 정확히 인식 | — |

## 브라우저 버전 (API 불필요)

claude.ai에 올린 페이지(Artifact)로 바로 씁니다: <https://claude.ai/artifact/APBdgkG9sx6URYhA2a3WWp> (기본은 본인만 열 수 있음 — 동료에게는 페이지의 공유 메뉴로 공유).
파일과 사진은 **브라우저 밖으로 나가지 않습니다**.

1. **STEP 1** Tool Verification 엑셀 선택 → **STEP 2** 사진(여러 장) 선택
2. 사진마다 찾은 툴과 날짜가 카드로 나옵니다.
   - 🟢 **자동 반영**: QR 또는 시리얼이 정확히 일치하고 날짜도 정상
   - 🟠 **확인 필요**: 손글씨가 애매함·교정주기 불일치 등 → *엑셀 대상 행*/날짜 확인 후 **엑셀에 반영** 체크
   - 🔴 **대상 없음**: 대상 행을 직접 선택
3. **엑셀 파일 만들기** → 저장 창에서 확인 → 같은 이름의 엑셀이 저장됩니다. 회사 공유 폴더의 원본을 이 파일로 바꿉니다.
4. 처음이라면 **예시로 해보기**로 전체 흐름(QR 스티커 사진, 손글씨 사진)을 먼저 볼 수 있습니다.

**인식 정확도 팁**
- 손글씨 시리얼은 오프라인 OCR로 읽고 엑셀의 시리얼 목록 중 가장 가까운 툴을 고릅니다. 비슷한 시리얼(예: `31550075`/`31550069`)이 있으면
  '확인 필요'로 멈추니 카드의 사진을 보고 대상 행을 고르세요. 원본 해상도(휴대폰 원본 사진)일수록 잘 읽습니다.
- **QR 스티커 탭**에서 스티커 PDF를 만들어 툴에 붙이면 사진 속 QR로 **항상 정확히** 찾습니다(교정필증과 한 장에 찍기).
- 교정필증(인쇄된 날짜)은 잘 읽습니다. 못 읽으면 날짜 칸에 직접 입력하면 됩니다(하나만 넣으면 교정주기로 나머지를 계산).
- STEP 2 아래 줄에 `글자 인식 준비됨`이 보이면 OCR이 동작 중입니다. 보안 설정으로 막힌 환경에서는 QR과 직접 선택만 사용합니다.

엑셀은 날짜 셀과 해당 행의 사진만 바뀌고, 다른 행·시트·사진·필터·SharePoint 속성은 그대로 유지됩니다.

`web/` 폴더를 사내 웹서버 등 정적 호스팅에 올려도 동작합니다(이 경우 OCR 엔진은 jsDelivr CDN에서 받습니다).

## Python 버전

### 1. 설치 (Windows, 최초 1회)

1. **Python 3.10 이상** 설치 — <https://www.python.org/downloads/> (설치 시 *Add python.exe to PATH* 체크)
2. 이 폴더의 **`install.bat`** 더블클릭 → 필요한 패키지가 `.venv` 폴더에 설치됩니다.
   - 회사 프록시 때문에 설치가 안 되면 IT 담당자에게 `pip` 프록시 설정을 요청하세요.
3. (선택) **Claude API 키** — 손글씨 자동 인식에 사용합니다. <https://console.anthropic.com> 에서 발급
   - 프로그램 왼쪽 설정의 *Claude API 키* 칸에 넣고 **설정 저장**을 누르거나,
   - Windows 환경변수 `ANTHROPIC_API_KEY` 로 등록합니다.
   - 키가 없으면 사진마다 대상 행과 날짜를 직접 고릅니다 (교정필증 자동 크롭·엑셀 반영은 그대로 동작). API 없이 자동 인식까지 원하면 브라우저 버전을 쓰세요.

### 2. 사용법 (웹 화면)

1. **`run.bat`** 더블클릭 → 브라우저에 `툴 검교정 관리` 화면이 열립니다.
2. 왼쪽 **엑셀 파일 경로**에 회사 엑셀 경로를 붙여넣고 **설정 저장** (다음부터 자동 입력)
   - OneDrive/SharePoint 동기화 폴더의 경로도 됩니다. 파일을 올려서 작업한 뒤 결과를 다운로드할 수도 있습니다.
3. **📷 사진으로 업데이트** 탭에 사진을 끌어다 놓기 (여러 장, 툴 사진과 SMAX 캡쳐 섞어도 됨) → **인식 시작**
4. 사진별 결과 확인
   - 🟢 **자동 반영** — 시리얼과 이름이 일치하고 날짜도 정상. 그대로 반영됩니다.
   - 🟠 **확인 필요** — 시리얼이 애매하거나, 이름이 다르거나, 교정주기와 날짜가 안 맞는 등. 내용을 보고 *엑셀 대상 행*/날짜를 고친 뒤 **엑셀에 반영** 체크.
   - 🔴 **오류** — 엑셀에서 툴을 찾지 못함. *엑셀 대상 행*을 직접 고르면 됩니다.
5. **엑셀에 반영** 버튼 → 저장 완료 화면에서 변경 내역(이전 → 새 날짜)을 확인합니다.

> 엑셀 파일이 **Excel에서 열려 있으면 저장할 수 없습니다.** 반영 전에 닫아 주세요.

#### 저장할 때 하는 일

| 항목 | 내용 |
|---|---|
| Cal Last / Cal Next | 교정필증의 교정일자 / 차기교정예정일자로 변경 (셀 서식은 기존 날짜 서식 그대로) |
| Label Photo | 그 행의 기존 사진을 지우고 **교정필증 부분만 잘라낸 사진**(기울기 보정)을 칸 크기에 맞춰 삽입 |
| SMAX Tool Photo | SMAX 캡쳐를 올린 경우에만 교체 |
| 백업 | 저장 전 원본을 `엑셀폴더\backup\파일명_날짜시간.xlsx` 로 복사 |
| 원본 사진 보관 | `엑셀폴더\검교정사진\지역\교정일_이름_시리얼.jpg` 로 정리 저장 + `update_log.csv` 에 변경 이력 기록 |

엑셀의 **다른 부분은 건드리지 않습니다** (다른 행·시트·사진·필터·SharePoint 속성 그대로).
반영 직전에 파일을 다시 읽고 시리얼로 행을 재확인하므로, 그 사이 누가 행을 추가해도 엉뚱한 행에 쓰지 않습니다.
`Cal Next` 가 수식(예: `=EDATE(B2,12)`)인 행은 수식을 유지합니다.

### 3. 사진 찍는 요령

- **한 장에 메모와 교정필증이 함께** 나오게 찍습니다 (예시: 툴 뒷면에 메모 + 교정필증).
- 메모에는 **이름**과 **시리얼 넘버**를 또박또박. 시리얼은 엑셀 `Serial` 열과 같은 값(문자 포함, 예: `44350259SV`).
- 교정필증 글자가 읽힐 정도로 가까이, 반사광 없이. 약간 기울어져도 자동 보정됩니다.
- 아이폰 HEIC 사진도 그대로 올리면 됩니다.

### 4. 판정 기준 (자동 반영 vs 확인 필요)

- **자동 반영**: 시리얼 정확히 일치(0/O, 앞자리 0 차이는 자동 보정) + 이름 일치(또는 이름 없음),
  또는 시리얼 1글자 차이지만 이름이 일치하고 다른 후보가 없을 때.
- **확인 필요**: 이름이 엑셀 담당자와 다름 · 시리얼 2글자 이상 차이 · 후보가 여러 개 ·
  폐기된 툴 · 차기교정일이 `Cal Interval`(6/12개월 등)과 3일 넘게 다름 · 기존보다 이전 교정일 · 미래 교정일 ·
  같은 툴 사진이 여러 장.
- 차기교정일을 못 읽으면 교정일 + `Cal Interval` 로 계산합니다 (반대도 동일).
- SMAX 캡쳐의 Calibration Due Date 가 새 차기교정일과 다르면 "SMAX를 먼저 수정했는지" 알려줍니다.

### 5. 엑셀 형식

시트마다 1행(또는 상단 10행 이내)에 아래 헤더가 있으면 됩니다. 열 순서는 상관없고, 시트(지역)를 추가해도 자동 인식합니다.

`Cal Next` · `Cal Last` · `Manufacturer` · `Model` · `Description` · `Serial` · `Asset #` · `Cal Interval` · `Cal Cycle` · `Label Photo` · `SMAX Tool Photo`

엔지니어 이름은 `Asset #` 값(예: `South_광주_CT_강건욱`)에서 읽습니다.

### 6. 명령줄 사용 (폴더 일괄 처리)

```bat
.venv\Scripts\activate
python -m toolcal update --excel "D:\Tool_Verification.xlsx" "D:\사진\2026-10" --dry-run   :: 미리보기
python -m toolcal update --excel "D:\Tool_Verification.xlsx" "D:\사진\2026-10"             :: 반영 (자동 반영 항목만)
python -m toolcal update ... --include-review                                               :: 확인 필요 항목도 반영
python -m toolcal status --excel "D:\Tool_Verification.xlsx" --days 30                       :: 만료/임박 목록
```

### 7. 참고

- **인식 엔진**: Claude API(기본 모델 `claude-opus-5-5`, 설정에서 변경 가능). 손글씨 한글 이름은 일반 OCR로는 읽기 어려워 비전 모델을 씁니다.
  엑셀에 있는 엔지니어 이름 목록을 함께 보내 손글씨 판독 정확도를 높입니다.
- **비용**: 사진 1장당 대략 수십 원 수준 (이미지 1장 ≈ 입력 3천 토큰).
- **보안**: 사진(이름·시리얼·교정필증)과 엔지니어 이름 목록이 Anthropic API로 전송됩니다. 회사 정책을 확인하세요.
  API 키는 이 PC의 `config.json` 에만 저장되며 git에는 올라가지 않습니다.
- 교정필증은 "흰색 직사각형 라벨"로 찾습니다. 못 찾으면 사진 전체를 넣고 화면에 알려줍니다.
